# Dynamic Product Dashboard (Vanilla JS)

## 📌 Project Overview
This project is a dynamic web dashboard that fetches and renders real-time product data from an external Store API. It serves as a technical demonstration of handling asynchronous operations in JavaScript using both `.then()`/`.catch()` syntax and the modern `async/await` pattern. 

The dashboard provides a clean user interface where product cards are generated dynamically based on API responses, complete with interactive hover effects for an enhanced user experience.

## 🚀 Technologies Used
*   **Language:** JavaScript (ES6+)
*   **Asynchronous Patterns:** Fetch API, Async/Await, Promises
*   **Styling:** CSS3 (Flexbox, Transitions, Hover Effects)
*   **Data Source:** [Course API - JavaScript Store Products](https://www.course-api.com/javascript-store-products)

## ✨ Key Features
*   **Multi-Pattern Fetching:** Implemented two distinct methods of API consumption to demonstrate versatility in JS logic.
*   **Dynamic DOM Manipulation:** Products are not hardcoded; they are created and appended to the document object model (DOM) upon a successful API call.
*   **Error Management:** Robust `try/catch` and `.catch()` blocks ensure the application handles network failures gracefully.
*   **Interactive UI:** Added polished CSS transitions including scaling and box-shadow depth on user interaction.
